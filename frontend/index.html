About AI Resume Analyzer

AI Resume Analyzer is an intelligent resume evaluation system developed using Machine Learning and Artificial Intelligence technologies.

The main goal of this project is to help recruiters and job seekers analyze resumes efficiently by detecting fake information, evaluating resume quality and providing useful improvement suggestions.

Technologies Used

Frontend: HTML, CSS, JavaScript

Backend: Python, Flask

Machine Learning: Python ML Model, Text Processing

AI Integration: Groq LLM API
