# AI Based Fake Resume Detection System

An AI-powered web application designed to analyze resumes and assist in identifying potentially fake or suspicious resumes using Machine Learning and Artificial Intelligence.

The system allows users to upload a PDF resume and provides resume classification, confidence score, ATS score, technical skill extraction, AI-powered resume analysis, improvement suggestions, and a downloadable PDF report.

## Key Features

* 📄 PDF Resume Upload and Text Extraction
* 🤖 Machine Learning-based Fake Resume Detection
* 📊 ATS Score Calculation
* 💻 Automatic Technical Skill Detection
* 🧠 AI-powered Resume Review using Groq API
* 💡 Resume Improvement Suggestions
* 📑 Downloadable Resume Analysis Report
* 🌐 User-friendly Web Interface

## How It Works

1. User uploads a resume in PDF format.
2. The system extracts the text from the resume.
3. The Machine Learning model analyzes the resume and predicts whether it appears Real or Fake.
4. The system calculates an ATS score based on resume content.
5. Technical skills are automatically detected.
6. Groq AI analyzes the resume and provides strengths, weaknesses, and improvement suggestions.
7. The user can download the complete analysis as a PDF report.

## Project Objective

The main objective of this project is to provide an AI-assisted resume screening and analysis platform that can help job seekers understand the quality of their resumes and assist recruiters in preliminary resume evaluation.
